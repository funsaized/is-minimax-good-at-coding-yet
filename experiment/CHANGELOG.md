# iteration 366 — the question holds the page together

A single composed page, read once. The vertical voice picker becomes a typesetter's reference; the composing-stick cell is dropped; the three-paper plate becomes a notation key; the signature folds into the colophon.

- **hero plate**: the title is set monumental (max 152px) inside a bordered plate with a top and bottom hairline rule. The three marked words stay as buttons, keyboard-navigable.
- **voice specimen**: the vertical pill picker is gone. In its place, a typesetter's reference — three stacked rows showing the line set in all three voices at once. Click any row to set the page in that voice.
- **opening pocket**: the five-column TOC is gone (it duplicated the right-edge ledger). The pocket keeps the opening premise, adds a single "first pull" line that previews the line in the current voice, and small folio chips as quick links.
- **press bed**: the composing-stick middle cell is gone. The press is now two cells — the lever with its three-row state readout (now / next / mark) and the pulled impression with a paper-corner curl.
- **notation key**: the three-paper specimen plate is replaced by a notation key — a four-column table (letter · the line, set · mark · a reading note) where each row is the same question in its voice. Click a row to lift it.
- **colophon**: the standalone signature is folded into the colophon. The closing now carries its own seal and one-line sign-off in one block.
- **topbar**: the voice badge is removed; only the brand and the date (with a small status dot) remain.
- **right-edge ledger**: panel now opens to the left of the trigger so it sits against the page body, not the screen edge.
- reduced-motion, keyboard focus, and mobile stacking all preserved.
