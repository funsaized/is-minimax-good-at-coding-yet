# Iteration 1

A warm composition: a hand-drawn question mark, a serif question, drifting dust — a page that nods when asked.

- Replaced the single line with a centered typographic composition built around the exact title.
- Added a hand-tuned SVG hero question mark (single stroke path + dot) in warm gold, with a draw-on entrance, a gentle continuous breath, and a considered nod on activation.
- Set the question in a system serif stack with balanced wrapping and a soft, delayed fade-rise so the page composes itself.
- Introduced a warm dark radial background and a canvas particle field that drifts, gently gravitates toward the pointer, and briefly shimmers when the question is acknowledged.
- Kept a single minimal top-left index mark; the hero is a real button, keyboard accessible with a focus ring and aria-label.
- Honored `prefers-reduced-motion`: static composition, no animation, no particle drift.
- Fully self-contained: system fonts, local SVG, CSS, and canvas. No remote assets or network calls.
- No fabricated metrics, iteration counts, testimonials, or fake status — only the question and its setting.
