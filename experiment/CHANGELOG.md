# Changelog

## 137 · the page earns a single quiet marginal voice

A small italic note now appears in the verso, between the answer and the
reply, set in two short lines in sepia and gold — the page speaking in
the reader's hand. After the second reading, the verso margin rule also
gains a fourth tick — "the reader, marked" — that fades in below the
answer tick. The recto colophon's hand-set rule is lightly feathered at
both ends so it reads as a single pulled pen line rather than a
gradient. Nothing else changes; the page's previous ornaments remain.
