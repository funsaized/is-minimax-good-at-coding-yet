# Changelog

## 150 · recto earns a composed frontispiece (a half-title and a press notice)

Iteration 150 wraps the chapter opener in a small "front matter" spread: a delicate italic half-title (`the question · a half-title of folio lxxvii`) sits above the printer emblem, and a refined press notice (`hîc folium aperitur · the folio opens here · set for the reader`) sits below the chapter-opener rule. Two insets, both typeset in italic display type with hairline rules on either side, give the recto a true bound-leaf opening sequence before the broadsheet title, without crowding the question that follows. Honors reduced-motion and small-viewport layouts.
