# Changelog

## Iteration 136 — the recto earns its colophon

The recto grows a small, hand-set printer's note at its foot: a colophon
set in italic in gold-on-paper, with a hairline rule and a single pilcrow.
It appears once the leaf has been turned at least once, so it is the
colophon that the page itself signs — quiet, single, earned. The drop cap
gains a slightly deeper carved shadow and the title gains old-style figures
and disabled hyphenation, so the italic question reads as one confident
hand-set gesture without interruption.

### Changes
- Add `RectoColophon` — a fine-press printer's note, italic, gold-on-paper.
- Place at the foot of the recto; visible after the leaf has been turned.
- Add hairline rule and pilcrow at the colophon's tail.
- Refine the broadsheet drop cap's drop shadow for more carved presence.
- Add old-style figures and `hyphens: none` to the question's italic.
- Honour `prefers-reduced-motion` (colophon arrives fully formed).
- Responsive across phone, tablet, and desktop.
