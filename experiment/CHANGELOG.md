# Changelog

## Iteration 362

A single composed opening: Reading Pocket, Opening Lede, and Folio Turn dividers replace the busy register.

- Composed the busy three-card right rail (reveal + ledger + reading note) into a single elegant Reading Pocket card with refined typography, corner ornaments, and a beautiful opening reveal.
- Removed the redundant running register between the header and the hero; the page now reads as one composed opening spread.
- Added an Opening Lede directly under the header: a single sentence ("one page, set three ways; the question stays open until the reader asks for the answer") set between two small printer's marks, with a quiet rule and a "read with / voice / set today" meta line that picks up the active voice.
- Replaced the simple "folio ii · the press bed" dividers with proper Folio Turns: each carries a folio number, a title, a short hint, and two small inked marks flanking a drawn rule.
- Tightened mobile composition: the Reading Pocket collapses to a single elegant card under the hero; the Folio Turns center gracefully.
- Added reduced-motion fallbacks for the new lede marks, lede rule, pocket arrows, and folio rule strokes.
