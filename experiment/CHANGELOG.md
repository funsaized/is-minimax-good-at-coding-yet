# Changelog

## Iteration 381 — the title page, held in one breath
The chase frame around the question is lightened — single hairline rule, smaller corner quoins — so the title feels set on a single, deliberate plate rather than framed by chrome. The voice column on the hero's side is rebuilt as a real typeset specimen: each voice is its own line, set in its own face, with the letter, name and face metadatum stacked beneath it. The press impression grows a slightly fuller type bed, the lever knob and shaft a few pixels taller and a touch heavier, and the proof line's stitches between folios carry a clearer bead and a longer thread. Section h2s and ledes pick up a touch more air, specimen plates and answer columns a touch more typographic confidence. The colophon title breathes more, the press coda reads cleaner, and the page reads as a single hand-printed broadside held open at first light.
