# Changelog

## Iteration 130 — a folio with memory
The recto earns its quiet marks of having been read. Three small additions — an
ink-bloom beneath the question mark, a reader's ink-mark in the corner, and a
page-signing rule beneath the question block — appear with restraint as the
answer sets, each telling the same quiet story: the page has been attended to.
A staggered verso choreography lets the answer breathe before the colophon,
ephemeris, and press signature arrive in sequence. Question typography gains a
half-step of weight and the teal subject gains a faint glow when answered.
